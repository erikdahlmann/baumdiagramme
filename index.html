🌿 Pfadregel (Produktregel)

Die Wahrscheinlichkeit eines Ergebnisses (ein vollständiger Pfad im Baumdiagramm) ist das Produkt der Wahrscheinlichkeiten entlang des Pfades.
Beispiel: P(0, 1, 1) = 15·45·45 = 16125.
0 / 5

➕ Summenregel

Ein Ereignis besteht aus mehreren Ergebnissen. Seine Wahrscheinlichkeit ist die Summe der Wahrscheinlichkeiten aller dazugehörigen Pfade (Ergebnisse).
Tipp: Bei „mindestens“ / „höchstens“ lohnt oft das Gegenereignis: P(E) = 1 − P(Ē).
0 / 5

🎯 Ergebnis vs. Ereignis – sauber aufschreiben

Ergebnis = ein einzelner Ausgang des Zufallsexperiments (ein Element von S).
Ergebnismenge S = Menge aller möglichen Ergebnisse.
Ereignis E = eine Teilmenge von S (kann ein, mehrere oder kein Ergebnis enthalten). Schreibweise immer als Menge: E = { … }.
0 / 5
